# CPU 시간 재기

설치는 [설치.md](설치.md)의 `설치.bat` 으로 해요. 이 문서는 설치한 뒤 무료 플랜에서 그림 한 장을 새로 그릴 때 CPU를 몇 ms 쓰는지 재는 방법이에요.
아래 `https://내주소` 는 설치 끝에 나온 주소(내 도메인이나 `…workers.dev`)로 바꿔 읽어요.

> 무료 플랜은 요청 한 번에 CPU **10ms**까지만 허용해요. 처음 그릴 때만 CPU를 많이 쓰고, 한 번 그린 그림은 저장본을 돌려줘서 거의 안 써요.
> 그래서 "처음 그릴 때 10ms 안에 들어오는지"만 확인하면 돼요. 안 들어오면 아래 방법으로 줄이고, 그래도 안 되면 그때 유료($5/월)로 바꾸면 됩니다.

## 재는 법

명령 프롬프트 **창을 하나 더** 열어서(같은 폴더에서) 로그를 켜 두어요.

```
npx wrangler tail --format json
```

그다음 브라우저에서 **값을 매번 바꿔서** 주소를 열어요. 값이 같으면 저장본이 나와서 재는 의미가 없어요. 첫 요청은 따로 느릴 수 있으니 같은 템플릿을 두 번씩 해 주세요.

```
https://내주소/demo/lite.webp?hp=11&gold=101
https://내주소/demo/lite.webp?hp=12&gold=102
https://내주소/demo/hud.webp?hp=21&name=가나
https://내주소/demo/hud.webp?hp=22&name=가나
```

터미널에 JSON이 줄줄 나오는데, 요청마다 `"cpuTime"` 이라는 숫자(ms)가 있어요. **lite 두 번, hud 두 번의 값**을 적어서 알려 주세요.
`cpuTime`을 못 찾겠으면 대시보드 왼쪽 메뉴 **빌드 → 컴퓨트 → Workers 및 Pages → (내 Worker) → 메트릭(Metrics)** 의 "CPU Time" 그래프(p50/p99)를 캡처해 주셔도 돼요.

### 결과에 따라 할 일

| 결과 | 할 일 |
|---|---|
| 10ms **이하** | 그대로 쓰면 돼요. |
| 10ms **넘음** | 아래 ①→②→③ 순서로 줄여요. |

① **크기를 줄이기**. `wrangler.local.jsonc`(버튼으로 설치했으면 내 저장소의 `wrangler.jsonc`)의 `"RENDER_SCALE": "1"` 을 `"0.75"`, 안 되면 `"0.5"` 로 바꾸고 설치기(`설치.bat`)를 다시 실행. 이미지가 작아지는 대신 CPU가 줄어요. (값을 바꾸면 이전 저장본은 자동으로 새로 그려져요.)
② **가벼운 템플릿 쓰기**. `lite`처럼 요소가 적고 그림(아이콘)이 없는 템플릿이 가장 빨라요.
③ 그래도 안 되면 **유료($5/월, Workers Paid)** 로 바꿔요. 코드는 그대로 두고 대시보드에서 플랜만 바꾸면 돼요.

## 자주 막히는 곳

- `wrangler`를 찾을 수 없다고 나옴 → 명령 앞에 `npx` 를 붙였는지, 판박이 폴더 안인지 확인해요.
- `Authentication error` → `npx wrangler login` 을 다시 해요.
- `https://내주소` 접속이 안 됨 → 내 도메인은 인증서가 만들어지는 동안 20분까지 걸릴 수 있어요.
- 그림의 한글이 네모(□)로 나옴 → 폰트가 안 들어간 거예요. `npm run font:subset` 뒤 `set BASE_URL=https://내주소`, `set ADMIN_TOKEN=관리토큰`, `node scripts/seed.mjs` 로 폰트와 샘플을 다시 넣어요(덮어써도 안전해요). 관리 화면의 폰트 메뉴에서 직접 올려도 돼요.
- `.jpg` 주소가 404 → 정상이에요. JPG는 느려서 기본으로 꺼 두었어요(`ENABLE_JPG`).
- `429 too many requests` → 같은 사람이 1분에 새 그림을 30장 넘게 요청하면 잠시 막아요(남용 방지). 1분쯤 기다려요.
