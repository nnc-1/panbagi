# 관리 화면 쓰기

브라우저에서 템플릿을 만들고 고치는 화면이에요. 주소는 **`https://내주소/admin`** 이고(`내주소`는 설치 끝에 나온 주소, 관리 화면 주소를 바꿨다면 그 주소),
처음 들어가면 설치할 때 받은 관리 토큰(`ADMIN_TOKEN`)을 한 번 넣어요. 토큰은 그 브라우저에만 기억되고, 오른쪽 위 **로그아웃**을 누르면 지워져서 다음에 토큰을 다시 넣어야 해요(누르면 한 번 더 물어봐요).
처음 설치했다면 채팅 목록의 **"한글 폰트와 샘플 넣기"** 를 한 번 눌러 한글 폰트와 샘플 템플릿을 넣어요.
오른쪽 위의 작은 숫자(예: `2026-10-22.3`)는 관리 화면 버전이에요. 새 코드를 배포했는데 이 숫자가 그대로면 예전 코드를 배포한 거예요.

> 관리 화면 파일은 Worker가 파일을 그대로 넘겨주기만 해서 **무료 플랜 CPU를 거의 쓰지 않아요.**
> 편집 중 미리보기도 브라우저가 그려요. 서버 CPU를 쓰는 것은 "게시"한 주소가 처음 그려질 때와 "서버로 렌더" 버튼뿐이에요.

### 관리 화면 주소 바꾸기

`/admin` 대신 나만 아는 주소로 바꿀 수 있어요.

**버튼으로 설치했으면 (추천)**

1. 🟠 **Cloudflare** <https://dash.cloudflare.com> → 왼쪽 메뉴 **빌드 → 컴퓨트 → Workers 및 Pages** → 내 Worker → **설정(Settings)** → **변수 및 비밀(Variables and Secrets)** → **+ 추가(Add)**
2. 🟠 **유형은 꼭 비밀(Secret)**, 이름 `ADMIN_PATH`, 값은 원하는 주소 이름(예: `my-panel_7`) → **배포(Deploy)**
3. 🟢 `https://내주소/my-panel_7` 로 열리는지 확인해요.

유형을 텍스트(Text)로 넣으면 다음에 GitHub에서 자동 배포될 때 지워져요. 비밀은 자동 배포가 건드리지 않아요.
GitHub 사본의 `wrangler.jsonc`에 적어도 동작은 하지만, 저장소를 보는 사람에게 주소가 보이고 기록에도 남으니 비밀로 넣어요.

**설치.bat으로 설치했으면**: 설치기가 처음에 물어봐요. 나중에 바꾸려면 💻 프로젝트 폴더에서:

```
npx wrangler secret put ADMIN_PATH
```

물어보면 원하는 주소 이름을 넣어요(예: `my-panel_7`). 영문·숫자·`-`·`_`만, 64자까지예요. 넣는 즉시 적용되고 배포를 다시 안 해도 돼요.
그러면 `https://내주소/my-panel_7` 에서 열리고, `/admin` 은 "없는 페이지"(404)가 돼요.

- 설정 파일(`wrangler.jsonc`, `wrangler.local.jsonc`)에 적지 말고 꼭 위의 secret으로 넣어요.
- 주소를 숨겨도 **관리 토큰은 그대로 필요해요.** 주소는 덧붙인 가림이고, 진짜 잠금은 토큰이에요.
- 채팅 이름과 같은 주소는 피하세요(그 채팅 이미지 주소가 가려져요). `admin`, `api`는 쓸 수 없어요.
- 되돌리려면 `npx wrangler secret delete ADMIN_PATH` → 다시 `/admin`.
- 주소를 잊었으면 `npx wrangler secret list`로는 이름만 보여서, 새로 `put` 하면 돼요.

## 0. 이 버전으로 올리기 (이미 설치해 둔 경우)

새 코드를 받고(git 폴더면 `git pull`, ZIP이면 원래 폴더에 덮어쓰기) **`설치.bat`** 을 다시 더블클릭하면 돼요.
이미 만든 저장소, 데이터베이스, 토큰, 템플릿은 그대로 두고 새 코드만 올려요. 자세한 건 [설치.md](설치.md)에 있어요.

## 1. 화면 구성

위쪽 메뉴가 세 개예요.

| 메뉴 | 하는 일 |
|---|---|
| **채팅·템플릿** | 채팅(캐릭터나 작품)을 만들고, 그 안의 템플릿을 만들고·고치고·지우고, zip으로 내보내고 가져와요. |
| **에셋** | 그림 파일(svg, png, webp, jpg)을 끌어다 놓아 올려요. 어느 템플릿이 쓰는지 보이고, 같은 이름으로 바꿔 끼우거나 **이름 바꾸기**로 이름을 고칠 수 있어요(쓰던 템플릿도 따라가요). 폴더로 나눌 수 있어요. |
| **폰트** | 한글 폰트를 올리고, 기본 폰트를 정해요. 한글 폰트가 없으면 이미지의 한글이 네모로 나와요. 폴더로 나눌 수 있어요. |

### 폴더

에셋과 폰트를 게임별로 나눠 둘 때 써요. 위쪽 줄에서 **전체**, **폴더 없음**, 각 폴더를 눌러 골라 봐요.

- **+ 새 폴더**로 폴더를 만들고, 그 폴더를 고른 채 파일을 올리면 그 안에 들어가요. 빈 폴더는 화면에만 있다가 파일을 넣으면 저장돼요.
- 카드(폰트는 줄)의 **옮기기**를 누르거나, 위쪽 폴더 이름 위로 끌어다 놓으면 옮겨져요.
- 폴더를 고른 상태에서 **폴더 이름 바꾸기**로 이름을 한꺼번에 바꿔요.
- 에셋은 이름 앞에 폴더가 붙어요(`던전/coin.svg`). 옮기거나 폴더 이름을 바꾸면 그 에셋을 쓰는 템플릿(예전 게시 버전까지)이 새 이름을 쓰도록 자동으로 바뀌어서, 이미지는 그대로 나와요.
- 폰트는 폴더가 폰트 이름(굵기 전체)에 붙는 꼬리표라서, 옮겨도 템플릿에는 아무 영향이 없어요.
- 편집기에서 에셋·폰트를 고르는 목록도 폴더별로 묶여 보여요.

## 2. 템플릿 만들기

> 처음이라면 예제 하나를 끝까지 따라 만드는 [템플릿 만들기 튜토리얼](템플릿-만들기.md)부터 보세요.

1. **채팅·템플릿 → + 채팅 추가**: 주소 이름(영문 소문자, 예: `dokki-rpg`)과 표시 이름을 넣어요.
2. 채팅에 들어가 **+ 템플릿 추가**: 주소 이름(예: `status`)을 넣고 시작할 모양을 골라요(빈 카드, 샘플, 다른 템플릿 복사).
3. 편집기가 열려요.

### 편집기

- **왼쪽 레이어**: 위에 있을수록 앞에 그려져요. 그룹·반복 안의 요소는 왼쪽에 세로선이 붙고, 고른 요소가 들어 있는 그룹의 선은 파랗게 보여요. 그룹 줄 옆에는 안에 든 요소 수가 나와요.
  끌어서 순서를 바꾸고, 그룹·반복 줄의 가운데에 놓으면 그 안으로 들어가요. 아래 칸에 그림 파일을 놓으면 올리고 바로 배치해요.
- **가운데 캔버스**: 누르면 고르고, 끌면 옮기고, 모서리 네모로 크기를 바꿔요. Shift를 누르고 끌면 가로나 세로로만 움직여요.
  고른 요소 위쪽의 **동그란 손잡이**를 끌면 가운데를 기준으로 돌아가요(Shift를 누르면 15°씩). 각도는 속성 탭 "회전 (도)"에서 숫자로 넣거나 "값에 따라" 바꿀 수도 있어요.
  겹친 곳에서 **이미 고른 요소를 한 번 더 누르면 그 아래 요소**가 골라지고, 맨 아래까지 가면 다시 맨 위로 돌아와요. 마우스를 올리면 다음에 골라질 요소가 점선으로 보여요.
  방향키는 1px(Shift는 10px), Delete는 삭제, Ctrl+D 복제, Ctrl+Z 되돌리기, Ctrl+S 초안 저장.
  그림 바깥 빈 바닥이나 레이어 맨 위 **캔버스** 줄을 누르면 선택이 풀리고 캔버스 속성이 나와요.
- **오른쪽 탭**
  - **속성**: 고른 요소의 위치(x, y, w, h), 색, 글자, 에셋 같은 값을 숫자로 고쳐요. 아무것도 안 고르면 캔버스 크기와 배경색이 나와요.
    **캔버스에 맞추기** 버튼(왼쪽·가운데·오른쪽, 위·가운데·아래)으로 고른 요소를 캔버스 가장자리나 한가운데에 붙여요. 지금 미리보기 값으로 그린 크기를 기준으로 해요.
    이미지의 **에셋** 칸에는 **에셋** 탭에 불러온 그림만 나와요. 새 그림은 에셋 탭에서 먼저 불러오고, **(없음)**으로 비울 수 있어요. "값에 따라"로 값마다 다른 그림을 고를 때도 줄마다 같은 목록에서 골라요.
    대부분의 칸 옆 **"값에 따라"** 를 누르면 그 값이 파라미터에 따라 바뀌게 만들 수 있어요.
    예: 게이지 색을 `hp`가 60 이상이면 초록, 30 이상이면 노랑, 그 밖엔 빨강(숫자 구간에 따라).
    **글자가 너비(w)를 넘칠 때**: 글자 속성에서 "글자 줄이기"(실제 폰트의 글자 폭으로 재서 칸에 맞게 줄임, "가장 작은 크기"까지 줄여도 넘치면 나머지를 숨김)나 "넘친 부분 숨기기"를 골라요. 너비(w)가 정해져 있어야 해요. 미리보기와 실제 그림이 같게 나와요.
    **여러 줄 글상자**: 툴바의 "+ 글상자"를 누르거나 글자 속성에서 "여러 줄 글상자"를 켜면, 너비(w) 안에서 띄어쓰기마다 줄이 바뀌어요(한 줄보다 긴 낱말만 글자 사이에서 끊어요). 내용 칸에서 Enter를 치거나, 챗봇이 값 안에 `\n`을 쓰면 그 자리에서 줄이 바뀌어요. 줄 간격, 세로 정렬(위/가운데/아래)을 고를 수 있고, "넘칠 때"는 박스 높이(h)까지 포함해 적용돼요. 글자 파라미터는 따로 정하지 않으면 500자까지 받고, 최대 글자 수는 2000자까지 늘릴 수 있어요.
    **게이지**는 "현재 값 ÷ 최대값(기준)"만큼 차요. 둘 다 파라미터로 받을 수 있어서, `hp=75`, `maxhp=150`이면 절반이 차요. 값이 이미 퍼센트면 최대값을 100으로 둬요.
    게이지 속성의 **+ 퍼센트 글자**(`50%`), **+ 값/최대 글자**(`75/150`) 버튼을 누르면 옆에 글자가 바로 생겨요. 글자 칸에 직접 `{hp|pct:maxhp}`라고 써도 돼요.
    **보이는 조건**으로 "a1이 none이 아닐 때만 보이기" 같은 것도 정해요.
  - **파라미터**: 주소로 받을 값(이름, 종류, 기본값, 범위, 설명)을 정해요. 이름을 바꾸면 요소에서 쓰던 곳도 같이 바뀌어요.
    **설명**을 채우면 챗봇 안내문에 들어가서 챗봇이 더 정확하게 써요.
    종류를 **무작위 (주사위)**로 하면 챗봇이 값을 보내지 않고 판박이가 굴려요(숫자 범위, 또는 적어 둔 목록에서 하나). 주소의 다른 값으로 굴리기 때문에 같은 주소는 늘 같은 결과이고, 값이 하나라도 바뀌면 새로 굴려요. 주소에 `hash=1~10000` 숫자를 붙이면 그 숫자도 섞어서 굴려요. 무작위 파라미터가 있으면 챗봇 안내문에 `hash` 줄이 자동으로 들어가서, 챗봇이 매 답변 다른 숫자를 넣으면 매번 새로 굴려요. 최소·최대는 숫자 파라미터로 정할 수도 있어요(예: `sides=20`이면 1~20).
  - **에셋**: 이 템플릿에 불러온 그림(별명 → 파일)과 폰트를 한곳에서 관리해요. 그림과 폰트 모두 **불러오기**로 가져오고, 다른 것으로 바꿔 교체하고, ✕로 빼요(에셋·폰트 메뉴의 파일은 그대로). 이미지와 글자 요소는 여기에 불러온 것 중에서만 골라요(기본 폰트는 늘 쓸 수 있어요). 폰트를 빼면 그 폰트를 쓰던 글자는 기본 폰트로 그려요.
  - **값·주소**: 미리보기 값을 바꿔 보고, 그 값으로 만든 이미지 주소·마크다운·**챗봇 안내문**을 복사해요. "서버로 렌더"는 실제 PNG를 만들어 보여 줘요(저장 안 함).
  - **JSON**: 템플릿 규칙 전체예요. 복사·붙여넣기나 고급 수정에 써요.
  - **버전**: 게시한 버전 목록이에요. 예전 버전을 편집기로 불러오거나, 이미지 주소를 예전 버전으로 되돌려요.
- 저장하지 않은 변경이 있을 때 뒤로 가기나 다른 메뉴로 나가려 하면 먼저 물어봐요.
- 위쪽 **초안 저장**은 서버에 저장만 하고, **게시**를 눌러야 이미지 주소(`/채팅/템플릿.webp`, `.png`로 써도 같은 그림)에 반영돼요.
  게시할 때마다 v1, v2…로 쌓이고, 주소 뒤에 `@2`를 붙이면(`status@2.webp`) 그 버전으로 고정돼요.

> 브라우저 미리보기는 글자 위치가 실제 PNG와 1~2px 다를 수 있어요. 딱 맞는지 볼 때만 "서버로 렌더"를 누르세요.
> 이미 채팅 화면에 뜬 이미지는 브라우저 캐시 때문에 저장본 수명(기본 6시간)까지 예전 모양일 수 있어요.

## 3. 챗봇에 붙이기

**값·주소** 탭의 **챗봇 안내문 복사**를 눌러 챗봇 캐릭터 설정(프롬프트)에 붙여 넣어요. 이런 글이 복사돼요.

```
[상태창 이미지]
매 답변 끝에 현재 상태를 아래 형식의 이미지 한 줄로 출력하세요. 주소는 바꾸지 말고 ? 뒤의 값만 채웁니다.
![](https://내주소/dokki-rpg/status.webp?name=값&hp=값)
- name: 캐릭터 이름. 글자, 최대 12자
- hp: 던전 체력. 숫자 0~100
값을 모르면 그 항목은 빼도 됩니다(기본값으로 그려짐). 글자 값의 공백은 %20으로 씁니다.
예시: ![](https://내주소/dokki-rpg/status.webp?name=도키&hp=72)
```

## 4. zip으로 내보내기·가져오기

- **내보내기**: 채팅 화면에서 템플릿 줄의 **zip**(하나) 또는 **전체 zip 내보내기**(채팅 전체). 템플릿과 쓰는 에셋이 들어가요.
  폰트는 "폰트 파일도 넣기"를 고를 때만 들어가요(재배포가 허락된 폰트만 넣으세요. Noto Sans KR은 OFL이라 괜찮아요).
- **가져오기**: 채팅 목록의 **zip 가져오기**. 넣을 채팅과 템플릿 이름을 정해요. 같은 이름의 에셋이 이미 있고 내용이 다르면 `-2`를 붙인 새 이름으로 올리고 템플릿이 그걸 쓰게 바꿔요.
  가져온 템플릿은 초안으로 들어가고, "바로 게시하기"를 고르면 게시까지 해요.
- 내보내기·가져오기는 브라우저에서 묶고 풀어서 서버 CPU를 거의 쓰지 않아요.

## 자주 막히는 곳

- 배포했는데 화면이 그대로 → 오른쪽 위 버전 숫자를 봐요. 그대로면 받은 ZIP이 예전 것이에요. 새 ZIP을 받아 **새 폴더**에 풀고 `npm install` 후 `npx wrangler deploy` 해요. 숫자는 바뀌었는데 화면이 예전 같으면 브라우저에서 Ctrl+F5로 새로고침해요.
- 토큰을 넣었는데 "관리 토큰이 맞지 않아요" → `npx wrangler secret put ADMIN_TOKEN` 으로 넣은 값과 같은지 확인해요.
- "서버에 ADMIN_TOKEN이 설정되지 않았거나 16자보다 짧아요" → 위 명령으로 16자 이상을 넣어요.
- 배포할 때 `esbuild`나 `preact`를 찾을 수 없다는 오류 → 새 코드를 받은 뒤 `npm install` 을 안 한 거예요. `npm install` 후 `npx wrangler deploy` 를 다시 해요.
- 미리보기의 한글이 네모 → **폰트** 메뉴에 한글 폰트가 있는지 봐요.
- 에셋 이름이 바뀌어서 올라감 → 주소에 쓸 수 없는 한글·공백이 빠진 거예요. 정상이에요.
- "서버로 렌더"가 실패 → 무료 플랜의 CPU 한도에 걸렸을 수 있어요. 캔버스 배율을 낮추거나 요소를 줄여요.
