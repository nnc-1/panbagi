# 판박이 설치와 업데이트

설치 방법은 두 가지예요. 코드를 몰라도 돼요.

| | 버튼으로 설치 | 설치.bat으로 설치 (Windows) |
|---|---|---|
| 필요한 것 | Cloudflare 계정, GitHub 계정 | Cloudflare 계정, Windows PC |
| 하는 일 | 웹 화면에서 버튼 몇 번 | 창에 나오는 질문에 답하기 |
| 내 도메인 연결 | 설치 뒤 대시보드에서 붙이고, 사본 저장소에서 한 줄 고치기 | 설치기가 물어보고 연결 |
| 업데이트 | GitHub에서 새 코드를 받아 와야 해요 | 새 코드를 받고 설치.bat 다시 실행 |

어디서 하는 일인지 단계마다 표시했어요: 🟠 **Cloudflare**(<https://dash.cloudflare.com>), ⚫ **GitHub**(<https://github.com>), 🟢 **관리 화면**(`https://내주소/admin`), 💻 **내 컴퓨터**.

## 1. 버튼으로 설치

순서와 **꼭 적어 둘 것**은 [README의 설치](../README.md#설치-5분-코드-몰라도-돼요)에 화면 그대로 적어 뒀어요.

## 2. 설치.bat으로 설치 (Windows)

### 준비물

1. **Cloudflare 계정** (무료로 돼요). <https://dash.cloudflare.com/sign-up>
2. Node.js는 **따로 설치하지 않아도 돼요.** 컴퓨터에 없으면 설치기가 설치 없이 쓰는 버전(약 30MB)을 이 폴더의 `.node` 안에 받아서 써요.
3. 이 코드. ⚫ **GitHub** <https://github.com/nnc-1/panbagi> 에서 **Code → Download ZIP**으로 받아 💻 내 컴퓨터 아무 데나 풀면 돼요.
4. **내 도메인** (Cloudflare 계정에 연결된 것). 설치기가 그 아래에 `svg.내도메인.com` 같은 주소를 만들어요.
   도메인이 없으면 임시 주소(`https://panbagi.<계정이름>.workers.dev`)로 설치하고 나중에 붙일 수 있어요.

### 설치

💻 **내 컴퓨터**: 내려받은 폴더의 **`설치.bat`** 을 더블클릭해요. 검은 설치 창이 열리고, 그 창에서 차례로 이렇게 해요.

| 단계 | 어디서 | 하는 일 | 나한테 묻는 것 |
|---|---|---|---|
| 1 | 🟠 **Cloudflare** (브라우저가 자동으로 열림) | Cloudflare 로그인 | 로그인하고 **Allow(허용)** 를 누른 뒤 💻 설치 창으로 돌아와요 |
| 2 | 💻 설치 창 | 설정 | Worker 이름(Enter), **내 도메인 번호와 앞 이름**(예: `1`, Enter → `svg.내도메인.com`), 관리 화면 주소(Enter면 `/admin`) |
| 3 | 💻 설치 창 | 이미지 저장소(R2) 만들기 | R2를 처음 쓰면 주소가 나와요. 그 주소를 🟠 **Cloudflare**에서 열어 R2를 켜고 💻 설치 창에서 Enter |
| 4~8 | 💻 설치 창 | 데이터베이스(D1), 설정 파일 `wrangler.local.jsonc`, 표 만들기, 올리기, 관리 토큰 만들기 | `workers.dev` 이름을 처음 정할 때 한 번 물어봐요 |
| 9~10 | 💻 설치 창 | 접속 확인, 한글 폰트와 샘플 넣기 | 없음 |

끝나면 💻 설치 창에 **관리 화면 주소**와 **관리 토큰**이 나와요. 그 주소를 브라우저에서 열면 🟢 **관리 화면**이에요.

> **관리 토큰은 그때 한 번만 보여 줘요.** 바로 복사해서 비밀번호 관리 앱이나 안전한 곳에 적어 두세요. 파일에는 저장하지 않아요.
> 잊어버렸으면 설치기를 다시 실행하고 "새로 만들까요?"에 `y`를 누르면 새 토큰이 나와요.

DNS 기록과 인증서는 설치기가 자동으로 만들어요. 인증서가 만들어지는 동안 **몇 분, 길면 20분** 걸리고, 설치기가 열릴 때까지 기다려 줘요.

### 업데이트

1. 새 코드를 받아요. git으로 받은 폴더면 그 폴더에서 `git pull`, ZIP이면 새 ZIP을 받아 **원래 폴더에 덮어써요**
   (원래 폴더의 `wrangler.local.jsonc`에 내 계정 값이 있어서, 새 폴더에 풀면 처음 설치처럼 질문을 다시 해요. 그래도 같은 답을 하면 괜찮아요).
2. **`설치.bat`** 을 다시 더블클릭해요.

이미 만든 저장소, 데이터베이스, 토큰은 그대로 두고 새 코드만 올려요. 템플릿과 그림도 그대로예요.
관리 화면 오른쪽 위 버전 숫자가 바뀌었으면 끝이에요.

### 바꾸고 싶을 때

- **주소(도메인)나 Worker 이름을 바꾸려면**: 폴더의 `wrangler.local.jsonc`를 지우고 설치기를 다시 실행해서 새로 답해요.
- **설정값**(저장본 수명, 크기 배율 등): `wrangler.local.jsonc`의 `vars`를 메모장으로 고치고 설치기를 다시 실행해요. 업데이트해도 고친 값은 남아요.
- **관리 화면 주소**: [관리-화면.md](관리-화면.md)의 "관리 화면 주소 바꾸기".

### 자주 막히는 곳

- **"Node.js를 받지 못했어요"**: 회사·학교 네트워크가 막았을 수 있어요. 열린 페이지에서 LTS를 직접 설치하고 설치기를 다시 실행해요.
- **R2를 켜 달라고 나옴**: 나온 주소에서 R2를 켜요(무료 사용량 안에서는 요금이 없지만 카드 등록을 요구할 수 있어요). 켠 뒤 Enter.
- **올리기 실패, 도메인 관련 메시지**: 그 도메인이 같은 Cloudflare 계정에 있는지 확인해요. 같은 이름의 DNS 레코드가 이미 있으면 지우거나 다른 이름을 써요.
- **계속 안 열림**: 20분 뒤 브라우저로 `https://내주소/healthz`를 열어 `ok`가 나오는지 봐요.
- **그 밖의 오류**: 창의 메시지를 캡처해서 알려 주세요. 설치기는 몇 번 다시 실행해도 안전해요.

## 직접 하고 싶은 사람

같은 일을 `npm install` 뒤 `npm run setup` 으로 할 수 있어요(Mac, Linux도 돼요).
저장소의 `wrangler.jsonc`에는 계정 값이 없고, 설치기가 이것으로 `wrangler.local.jsonc`(git에 안 올라감)를 만들어 늘 그 파일로 올려요.
손으로 올릴 때는 `npx wrangler deploy -c wrangler.local.jsonc`.
